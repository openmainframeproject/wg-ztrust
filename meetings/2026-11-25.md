## Review Z Day Cryptography and ZTRUST Presentation

Igor and Rick as well as Jonathan McDowell presented at Z Day,
"Securing the Open Source Software Supply Chain with Cryptography".
Lyz reports that the talk went really well. A replay is available
and will be migrated to un-registered download after about a month.

During the presentation, Berry had asked about disclosure or publication
of email addresses by way of PGP. The PGP key filename template includes
the email address field. Lyz pointed out that when a PGP key is imported
the email address is revealed anyway *and* that those who wish to conceal
their email address have means within current key handling methods.
The email address being embedded in the filename does make it more visible.

## New Key Added: ZOPEN

Igor had initiated a Git "pull request" to add the zopen community
signing key for attestation. He named the key file perfectly following
the template. He then manually added it to `pgp-bundle.asc`. That's fine,
but recreating the "bundle" can be automated.

    cat 0x*.asc > pgp-bundle.asc

Igor also created a sub-directory `projects`. This is fine, but an
open question is: should there be per-project directories under it?

Finally, Igor uploaded sample configuration for Hashcorp "Vault Radar".
Some might be concerned about vendor influence or favoritism, but
this has become a defacto-standard. All agreed it should remain.

## Historical Code Collections

At the end of the call, Berry, Mike, and Rick had lengthy discussion
about existing code collections (e.g., the VM Workshop tape, the CBT
tape, etc). An ongoing effort is to encourage contributors to these
collections to sign their wares. But many older packages are included
for which the author(s) are no longer available. It was suggested
that there be a listing of hashes of these files for verification.
