## Quick Certificate Request

Rick shared a one-page makefile for use by VSSI customers
to create a private key and a certificate request. The up-coming product
will require a server certificate (where customers choose to use SSL)
and VSSI wants to simplify as much as possible.

Good feedback.

## Quick PGP Code Signing

Rick shared a short shell script which he is using for signing
Linux deliverables (for the same VSSI product). Where RPM is employed,
the `rpmsign` command is part of the recipe.

Good feedback.

## Great Introduction by Charles Mills

On the RACF-L discussion list, Charles Mills responded to a request for
"Digital Certificates of Idiots" with a recording of his presentation
(now five years old, but still highly accurate and completely relevant).
Charles gave permission for ZTRUST to include a link to his presentation.
(The MP4 file itself is on the order of 100M so we're not likely
to upload it to the repository.)

Everyone is encouraged to view the recording.
